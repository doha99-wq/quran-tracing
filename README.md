# تطبيق نسخ القرآن الكريم بالقلم

تطبيق Flutter لنسخ صفحات القرآن بالقلم على التابلت، يبدأ بسورة الفاتحة.

## التشغيل

```bash
git clone https://github.com/doha99-wq/quran-tracing.git
cd quran-tracing
flutter pub get
flutter run
```

## الملفات

- `lib/main.dart` — كل كود التطبيق
- `pubspec.yaml` — الاعتماديات

## الخطوة التالية

أضف صورة صفحة الفاتحة الحقيقية في `assets/images/` (مثلاً من https://github.com/GovarJabbar/Quran-PNG) واستبدل النص المرجعي بصورة.
